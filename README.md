# VaultPixel Gear - Interactive E-commerce Milestone

VaultPixel Gear is a responsive e-commerce prototype for gaming accessories and desk-setup gear.

## Pages
- `index.html` - Store homepage
- `shop.html` - JavaScript-rendered catalog with 12 products
- `product.html` - Product details prototype
- `contact.html` - Contact form with validation
- `cart.html` - Shopping cart prototype
- `checkout.html` - Purchase, shipping, validation, and coupon discount features
- `styles.css` - Shared responsive brand styling
- `app.js` - Product data, loops, form validation, totals, and coupon logic

## Interactive Milestone Features
- 12 products stored in JavaScript and rendered with a loop
- Responsive product grid
- Contact form: Full Name, required Email, Subject, required Message
- Checkout purchase form with required card fields
- Checkout shipping form with required shipping fields
- JavaScript required-field validation
- Email, phone, ZIP, card number, expiration, and security-code validation
- Coupon codes:
  - `SAVE10` = 10% off orders of at least $50
  - `PIXEL15` = 15% off orders of at least $100
  - `SETUP20` = 20% off orders of at least $150
- Dynamic order subtotal, discount, shipping, and total calculations
